# User Guide

NewsBot 2.0 is designed to help users analyze and understand news articles.

## Basic Use

1. Open the final NewsBot 2.0 notebook in Google Colab.
2. Run the setup and model cells.
3. Enter or use sample news text.
4. Run the analysis tools.
5. Review the results.

## Main Features

Users can:

- Analyze article sentiment
- Find important entities
- Discover topics
- Create summaries
- Search for related articles
- Detect languages
- Translate Spanish text into English
- Ask natural language questions
