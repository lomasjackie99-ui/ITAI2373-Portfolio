# API Reference

## TextPreprocessor
Cleans and prepares article text.

## FeatureExtractor
Creates TF-IDF features from documents.

## NewsClassifier
Trains and predicts news categories.

## SentimentAnalyzer
Analyzes positive, negative, or neutral sentiment.

## EntityExtractor
Finds people, places, organizations, and other named entities.

## TopicModeler
Uses LDA or NMF to discover topics.

## IntelligentSummarizer
Creates shorter article summaries.

## SemanticSearchEngine
Finds articles related to a user query.

## LanguageDetector
Detects the language of input text.

## Translator
Translates Spanish text into English.

## IntentClassifier
Identifies what a user is asking NewsBot to do.

## QueryProcessor
Processes natural language questions.

## ResponseGenerator
Creates responses from NewsBot results.
