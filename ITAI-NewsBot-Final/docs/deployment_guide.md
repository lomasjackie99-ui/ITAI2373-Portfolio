# Deployment Guide

NewsBot 2.0 currently runs in Google Colab.

## Running the Project

1. Open the final NewsBot 2.0 notebook.
2. Connect to a Google Colab runtime.
3. Install or import the required libraries.
4. Run the notebook cells in order.
5. Review the system results and visualizations.

## Future Deployment

A future version could be deployed as a web application using tools such as Flask or Streamlit.
